# Contributing to SheetLab

Thank you for your interest in contributing to SheetLab! We welcome contributions from the developer community.

## How to Contribute

1. **Fork the repository** on GitHub
2. **Clone your fork** to your local machine
3. **Create a feature branch** (`git checkout -b feature/amazing-feature`)
4. **Make your changes** following the existing code style
5. **Test your changes** (`npm run test:unit` and `npm run test`)
6. **Commit your changes** using conventional commit messages
7. **Push to your branch** (`git push origin feature/amazing-feature`)
8. **Open a Pull Request** against the `main` branch

## Development Setup

See the [Development section in README.md](README.md#development) for setup instructions.

## Code Style

- Use ESLint and Prettier (run `npm run lint` and `npm run format`)
- Keep the webview lightweight (no heavy frameworks)
- Maintain strict CSP in webviews
- Add tests for new functionality
- Update documentation as needed

## Reporting Bugs

Please use the [GitHub Issues](https://github.com/AnandShah10/sheetlab/issues) with a clear title, description, and reproduction steps.

## Feature Requests

We love hearing your ideas! Open an issue with the `enhancement` label.
